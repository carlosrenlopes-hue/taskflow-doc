# Projects

A project is a container for tasks. Each project receives a unique `project_id` when it is created.

## Create a project

Use `POST /projects` to create a project.

The `name` field is required. `description` is optional.

```json
{
  "name": "Documentation project",
  "description": "Improve the API documentation."
}
```

The API returns the generated `project_id`:

```json
{
  "project_id": "PROJECT_ID",
  "name": "Documentation project",
  "description": "Improve the API documentation.",
  "created_at": "2025-05-12T10:30:00.000Z"
}
```

<Note>
Keep the `project_id`. You need it to create tasks and list tasks for the project.
</Note>

## Project fields

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `project_id` | UUID | No | Generated automatically. |
| `name` | string | Yes | The project name. |
| `description` | string | No | An optional project description. |
| `created_at` | date-time | No | Creation timestamp generated by the API. |

For the complete request and response reference, see the [API Reference](/api-reference/overview).
